IMPORTANT PROJECT CONTEXT
==================================================

==================================================

Record ownership

API permissions

Every protected operation must be secure even if a malicious user directly calls the API.

8. ORGANIZATION / TENANT ISOLATION
==================================================

If Qubit One supports multiple organizations/tenants, enforce strict isolation.

Every relevant record must belong to the correct organization/tenant.

Prevent:

Cross-tenant reads
Cross-tenant updates
Cross-tenant deletes
Cross-tenant exports
Cross-tenant search
Cross-tenant AI retrieval

Never rely only on frontend filtering.

Test deliberately for IDOR/BOLA-style vulnerabilities.

Example:

User A must not access:

/customers/{user-B-customer-id}

simply because the ID is known.

Backend must verify authorization.
